# 🤖 AI Powered Interview Preparation System

An AI-powered interview preparation platform that analyzes resumes and dynamically generates interview questions with adaptive difficulty.

## 🚀 Features
- Resume-based question generation
- Technical, HR, and project-based questions
- AI interviewer interface
- Secure authentication using JWT

## 🛠 Tech Stack
- Frontend: React/Next.js
- Backend: Node.js, Express
- AI/ML: Python, NLP models
- Database: MongoDB
