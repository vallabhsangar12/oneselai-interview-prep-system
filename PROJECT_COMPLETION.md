## 🎉 Project Overview

The OneselfAI platform is a comprehensive, production-ready AI-powered interview preparation system designed to help professionals practice and improve their interview skills through intelligent facial emotion detection, voice analysis, and detailed performance feedback.

## 🔧 Technology Stack

### Frontend
- **Framework**: Next.js 16
- **Language**: TypeScript
- **UI Library**: shadcn/ui
- **Styling**: Tailwind CSS v4
- **State Management**: SWR, React Hooks
- **Notifications**: Sonner
- **Icons**: lucide-react

### Backend
- **Runtime**: Node.js
- **Framework**: Next.js API Routes
- **Authentication**: JWT + bcrypt
- **Database**: PostgreSQL (optional)
- **ORM**: Raw SQL (with fallbacks)

### Deployment
- **Primary**: Vercel
- **Alternative**: Traditional server
- **Database**: PostgreSQL on any provider
- **Storage**: Vercel Blob or local
